#  App de Gestão de Orçamentos - Unileste

Sistema mobile desenvolvido para a disciplina de Desenvolvimento Mobile. O aplicativo permite o gerenciamento completo (CRUD) de orçamentos de serviços, com persistência de dados local.

##  Funcionalidades
- Criar novos orçamentos com múltiplos itens/serviços.
- Listagem de orçamentos com filtros por status.
- Edição de orçamentos existentes (sem duplicação).
- Visualização detalhada e exclusão de orçamentos.
- Persistência de dados offline com AsyncStorage.

##  Tecnologias Utilizadas
- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [React Navigation](https://reactnavigation.org/)
- [AsyncStorage](https://react-native-async-storage.github.io/async-storage/)
